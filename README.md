# 📉 Customer Churn Prediction & Retention Dashboard

End-to-end machine learning project for predicting customer churn and simulating data-driven retention strategies.

## 🚀 Features

- XGBoost churn prediction model
- Confusion matrix & ROC curve evaluation
- High-risk customer segmentation
- Tenure-based churn analysis
- Contract-type churn comparison
- Retention revenue simulation
- Interactive Streamlit dashboard
- CSV export of high-risk customers

## 🧠 Business Impact

Targeting the top high-risk customers allows organizations to reduce churn efficiently while controlling intervention costs.

## 🛠 Tech Stack

- Python
- Pandas / NumPy
- Scikit-learn
- XGBoost
- Streamlit
- Matplotlib / Seaborn
